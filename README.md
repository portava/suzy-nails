# Suzy Nails & Total Care website

Website for Suzy Nails & Total Care, 109 Trần Phú, Đà Nẵng.
Pages: English (`index.html`), Korean (`ko.html`), Chinese (`zh.html`), Japanese (`ja.html`), Vietnamese (`vi.html`).

- Edit text, photos and layout in `src/template.html`, then run `node src/build.js` (needs Playwright) to rebuild the five pages.
- Every push to `main` publishes the site with GitHub Pages (`.github/workflows/pages.yml`).
